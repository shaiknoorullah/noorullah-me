# GRADE.md — The Substrate grade spec

The cinematic grade for the Substrate scene (noorullah.me v2). One source of truth:
`acts.json` (generated by `grader.py --dump-acts`) carries every number below; the
runtime `GradeEffect` and the offline grader both read from it.

Diagnosis this grade answers: frames render washed — midtones sit high, blacks sit at
0 (dead, not rich), and there is no temperature separation between shadow and light.
The grade restores contrast with an S-curve, rebuilds black density with a floor at
~6 IRE (never 0), and adds the warm-highlight / cool-shadow split that makes a dark
void read as *film*, not render.

References: `../CINEMATIC-LIGHTING.md` §6 (grade targets), aten7.com's final
composite (`uBlueCurve` 1D blue-channel LUT, see
`../../aten7-capture/PART3-WEBGL.md` §4), Resn's map-grade pass.

---

## 1. Pipeline order (exact)

Input: AgX-rendered frame, sRGB-encoded, float [0,1] per channel.
All ops are per-pixel except halation (spatial blur) and grain (stochastic).
The 3D LUT bakes steps 1–7 only (the point-wise color ops). Halation, grain and
vignette stay live effects — the runtime already owns them (Bloom / Grain / Vignette
in the §4.4 post stack).

```
1  exposure      x *= 2^exp                                  (per act, stops)
2  temperature   r *= 1 + 0.08·t ;  b *= 1 − 0.10·t          (t per act, −1..+1)
                 clamp(x, 0, 1)
3  saturation    L = dot(x, (0.2126, 0.7152, 0.0722))
                 x = clamp(L + (x − L)·sat, 0, 1)
4  S-curve       k = ln(0.5)/ln(p)  (p = pivot, per act)
                 S_p(u) = ( S(u^k) )^(1/k),  S(w) = 3w² − 2w³
                 x = x + c·(S_p(x) − x)                      (c = contrast, per act)
5  split tone    shadowMask = smoothstep(0.45, 0.00, L)      (1 at black)
                 hiMask     = smoothstep(0.55, 1.00, L)
                 x = mix(x, TINT_S · (L / LUMA_S), 0.08 · shadowMask)
                 x = mix(x, TINT_H · (L / LUMA_H), 0.05 · hiMask)
                 TINT_S = #3552E8 → (0.20784, 0.32157, 0.90980), LUMA_S = 0.33996
                 TINT_H = #FF6B1A → (1.0, 0.41961, 0.10196),    LUMA_H = 0.51997
6  blue curve    b = blueCurve_act(b)    — aten7 uBlueCurve pattern, §4
7  black floor   x = floor + (1 − floor)·x                   (floor per act, IRE)
8  halation      hot = smoothstep(0.80, 0.95, L)
                 x = clamp(x + halGain · gaussBlur(x · hot, radius 6px @720p))
9  grain         x += grainAmt · n · (0.35 + 0.65·(1 − L))
                 n = per-channel gaussian noise, σ = 1, seeded
10 vignette      r_n = dist(uv, center) / 0.7071
                 x *= 1 − vig · smoothstep(0.55, 1.35, r_n)
11 clamp → 8-bit sRGB
```

Notes:
- **Contrast c + pivot p**: the S-curve's maximum slope (`1 + 0.5·c`, c = 0.38 →
  1.19×) sits *at the pivot*, not at 0.5. This is a low-key film — the board's lit
  surfaces live at 0.1–0.4, so the pivot drops to 0.35–0.42 to put the contrast
  where the subject is: values below the pivot gain density, the key side separates.
  Act 3's top-down is the brightest frame and keeps the highest pivot (0.42).
- **Black floor** 0.05–0.07 ≈ 5–7 IRE, per §6: "floor at ~5–8 IRE equivalent — never
  crush to 0." Darker acts get a *higher* floor (rich blacks need surviving detail);
  the finale (Act 5) gets the deepest floor for maximum contrast on the wide master.
- **Halation** blooms only the hottest pixels (the green emissive, rim glints) —
  §6 Fog Glow analog. Act 5's "bloom lift" from DESIGN is the raised halation gain.
- **Act 4 vignette +10%** is DESIGN's per-act note; the base vignette (.28/.72)
  still lives in the post stack.

## 3. S-curve definition

Pivot-shifted smoothstep, applied per channel, blended by contrast c:

```
k     = ln(0.5) / ln(p)                     (warp exponent; maps pivot p → 0.5)
S_p(u) = ( 3w² − 2w³ )^(1/k)   where w = u^k
x'    = x + c·(S_p(x) − x)
```

Properties: endpoints pinned (S_p(0)=0, S_p(1)=1) — whites never clip harder, the
black floor (step 7) still owns the toe; slope at the pivot p is exactly
`1 + 0.5·c`; p = 0.5 degenerates to the plain smoothstep blend. Deliberately *not*
a filmic/ACES curve — AgX already owns highlight rolloff; this curve only restores
midtone separation lost in the flat render, placed where a low-key frame actually
lives (p = 0.35–0.42).

## 4. Blue-channel curve LUT (aten7 uBlueCurve pattern)

aten7 grades its eras by swapping a bound 1D LUT sampled as
`texture2D(uBlueCurve, vec2(b, 0.))` — the blue channel carries the era's
temperature signature. We adopt the same mechanism: **one 256×1 blue curve per act**,
control points below, monotone Hermite (finite-difference tangents) interpolation:

```
m_i   = (y_{i+1} − y_{i−1}) / (x_{i+1} − x_{i−1})      (interior; one-sided at ends)
seg   = between control points P1=(x1,y1), P2=(x2,y2)
t     = (b − x1)/(x2 − x1) ,  h = x2 − x1
b'    = (2t³−3t²+1)·y1 + (t³−2t²+t)·h·m1 + (−2t³+3t²)·y2 + (t³−t²)·h·m2
clamp(b', 0, 1)
```

Control points `(x, y)` per act (blue in → blue out):

| Act | Points |
|-----|--------|
| 0 | (0, .015) (.20, .210) (.50, .485) (.80, .815) (1, .990) |
| 1 | (0, .030) (.20, .230) (.50, .500) (.80, .820) (1, 1.000) |
| 2 | (0, .012) (.20, .205) (.50, .490) (.80, .810) (1, .995) |
| 3 | (0, .010) (.20, .200) (.50, .480) (.80, .800) (1, .980) |
| 4 | (0, .020) (.25, .250) (.50, .490) (.75, .770) (1, .990) |
| 5 | (0, .020) (.20, .200) (.50, .470) (.80, .780) (1, .960) |

Reading: every act keeps a **cool toe** (blue lifted at black, reinforcing the
#3552E8 shadow split) and acts 3/5 pull blue down through the highlights (warmth).
Act 1 is the cool outlier — lifted across the whole range, per DESIGN's
"cooler, temp −0.1". Curves are near-identity in the mids so the green signal
(#A4EB53, blue channel 0.325) drifts ≤ ±0.01.

Baked LUTs: `luts/bluecurve-act{0..5}.png` (256×1, sample `texture2D(lut, vec2(b, .5))`).

## 5. Split toning

- Shadows toward **#3552E8** at 8% (`0.08 · shadowMask`), highlights toward
  **#FF6B1A** at 5% (`0.05 · hiMask`).
- Luma-preserving form: `mix(x, tint · (L / tintLuma), amt·mask)` — shifts hue
  without pumping brightness, so the void stays a void.
- Masks: `shadowMask = smoothstep(0.45, 0.00, L)`, `hiMask = smoothstep(0.55, 1.00, L)`.
  Midtones (0.45–0.55) are untouched — skin of the grade, no mid murk.

## 6. Halation + grain (live effects, not in the LUT)

- **Halation:** mask `smoothstep(0.80, 0.95, L)` × frame, gaussian blur radius 6 px
  at 1280×720 (scale linearly with resolution), add back at per-act gain (0.25–0.40).
  Only the green emissive and hottest rim glints cross the threshold — §6's
  "threshold set so only G and the hottest rim glints bloom." Runtime equivalent:
  the existing Bloom pass with threshold raised from .72 → .80, or a dedicated
  masked bloom; DESIGN's Act-5 "bloom lift" = halation gain 0.40.
- **Grain (35mm):** per-channel gaussian noise, σ=1, scaled by
  `grainAmt · (0.35 + 0.65·(1 − L))` — grain lives in the shadows like film, dies in
  highlights. grainAmt 0.016–0.018 ≈ 35mm at 720p–1080p. Runtime equivalent: the
  existing premultiplied Grain effect (.55 opacity) with the same luma rolloff.

## 7. LUT exports

| File | Format | Contents |
|------|--------|----------|
| `luts/substrate-act{0..5}.cube` | Adobe .cube, `LUT_3D_SIZE 33` | Steps 1–7 baked (point-wise grade), sRGB in → sRGB out |
| `luts/substrate-act{0..5}-lut32.png` | 1024×32 strip, 32 tiles of 32×32 | Same grade as three.js LUT texture (postprocessing `LUT3DEffect` / `LookupTexture`; slice = b·31, x = r·31, y = g·31) |
| `luts/bluecurve-act{0..5}.png` | 256×1 | §4 blue curves, aten7 pattern |

LUT domain note: the LUTs are **display-referred (post-AgX, sRGB)**. In the runtime
stack (§4.4: `Grade → Grain → Vignette → AgX`), Grade runs *before* AgX on linear
HDR values, so **do not sample these LUTs there** — implement §1 steps 1–7 as shader
math (GLSL below) on the linear input; the functions are space-agnostic. The baked
LUTs are for the Blender compositor, stills, and any post-AgX slot.

## 8. Runtime GradeEffect — reference GLSL

```glsl
uniform float uExp, uTemp, uSat, uContrast, uPivot, uFloor;
uniform sampler2D uBlueCurve; // 256x1, per act

vec3 substrateGrade(vec3 x) {
    x *= exp2(uExp);                                   // 1 exposure
    x.r *= 1.0 + 0.08 * uTemp;                         // 2 temperature
    x.b *= 1.0 - 0.10 * uTemp;
    x = clamp(x, 0.0, 1.0);
    float L = dot(x, vec3(0.2126, 0.7152, 0.0722));
    x = clamp(L + (x - L) * uSat, 0.0, 1.0);           // 3 saturation
    float k = log(0.5) / log(uPivot);                  // 4 S-curve (pivot-shifted)
    vec3 w = pow(max(x, 1e-6), vec3(k));
    vec3 s = w * w * (3.0 - 2.0 * w);
    vec3 sp = pow(max(s, 1e-9), vec3(1.0 / k));
    x = x + uContrast * (sp - x);
    L = dot(x, vec3(0.2126, 0.7152, 0.0722));
    float shM = smoothstep(0.45, 0.0, L);              // 5 split tone
    float hiM = smoothstep(0.55, 1.0, L);
    vec3 TS = vec3(0.20784, 0.32157, 0.90980);         // #3552E8
    vec3 TH = vec3(1.0, 0.41961, 0.10196);             // #FF6B1A
    x = mix(x, TS * (L / 0.33996), 0.08 * shM);
    x = mix(x, TH * (L / 0.51997), 0.05 * hiM);
    x.b = texture2D(uBlueCurve, vec2(x.b, 0.5)).r;     // 6 blue curve
    x = uFloor + (1.0 - uFloor) * x;                   // 7 black floor
    return clamp(x, 0.0, 1.0);
}
```

Drive `uExp/uTemp/uSat/uContrast/uPivot/uFloor/uBlueCurve` from `acts.json` through the
Director, lerped on act transitions (same spring as the camera). Halation = Bloom
(threshold .80), grain = Grain with the §6 luma rolloff — both already in the stack.
